# 🚀 Agenda Fácil - Automação & CRM

Sistema web interativo desenvolvido para otimizar o fluxo de agendamentos e vendas, integrado diretamente com o WhatsApp.

## 🌟 Funcionalidades Principais
* **Apresentação Comercial em Slides:** Demonstração visual interativa das vantagens do sistema.
* **Agendamento Inteligente:** Escolha de modalidades entre contratação direta ou agendamento de demonstração ao vivo com data e horário.
* **Painel ADM / CRM:** Ferramenta de gestão com métricas em tempo real e controle de acesso protegido por PIN.
* **Disparo Automático:** Redirecionamento dinâmico e formatado para o WhatsApp comercial.

## 🛠️ Tecnologias Utilizadas
* **Frontend:** HTML5, CSS3, JavaScript (Vanilla).
* **Hospedagem & Deploy:** GitHub Pages / Netlify.
